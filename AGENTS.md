# AGENTS.md

Les règles de ce dossier vivent dans **[CLAUDE.md](CLAUDE.md)**. Elles valent pour tout agent qui travaille ici, quel que soit l'outil.

Lis-le avant toute action. En résumé, les trois règles qui priment :

1. **Un dossier = une chaîne = un avatar = un segment = un produit.** Rien de ce dossier ne parle d'un autre produit.
2. **Tout se pilote en conversation.** Aucun frontend, jamais.
3. **Aucune clé d'API n'est jamais écrite en clair** — ni dans un fichier versionné, ni dans un log, ni dans une réponse.

Le savoir-faire détaillé est dans `.claude/skills/`. Les commandes sont dans `.claude/commands/`.
